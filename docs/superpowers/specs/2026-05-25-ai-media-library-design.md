# AI 多媒体素材整理工具设计

## 背景

这个项目从空仓库开始，目标是开发一个本地素材库工具，辅助用户整理大量驳杂的多媒体素材，包括视频、照片、音乐等。第一版聚焦本地文件管理、增量导入、视频和图片 AI 标签解析、视频帧预览和多条件筛选。音频文件第一版只做基础索引和文件级筛选，音乐的 BPM、情绪、歌词等深度解析放到后续扩展。

典型场景是“牛仔面料工厂”主题素材库：用户导入本地目录后，系统识别视频和图片中的牛仔布、缝纫机、裁剪布料、熨烫面料、产品册、人物等画面信息，并识别视频谈话内容，支持中文、英文、俄文等语言。用户可以按标签、字幕、主题、文件类型和时间点筛选素材。

## 第一版定位

第一版采用本地桌面 Web 应用形态：应用在本机运行，用户通过浏览器访问本地地址。原始素材默认不移动、不重命名、不修改，只建立索引、缩略图、抽帧结果、字幕和标签。AI 识别优先调用云端 API，本地负责扫描、媒体处理、任务调度和索引。

这个版本不做团队协作、多用户权限、云端素材托管和完整原生桌面打包。后续如果核心体验验证成功，可以再封装为 Electron 或 Tauri 桌面应用。

## 目标

- 支持导入本地目录或移动硬盘目录，建立素材库索引。
- 支持增量导入，新文件和变更文件进入后台解析队列。
- 默认不破坏原始素材；复制、移动、重命名必须由用户显式确认。
- 支持视频缩略图、关键帧预览、时间点标签和字幕片段。
- 支持图片按文件路径、地点信息、EXIF 信息和画面内容打标。
- 支持音频文件按路径、文件名、大小、时长和格式做基础索引。
- 支持云端 AI 识别画面标签、语音内容和语言信息。
- 支持手动主题和 AI 推荐主题结合，例如“牛仔面料工厂”。
- 支持按主题、标签、语言、字幕文本、文件类型、路径和时间点筛选素材。
- 支持解析任务暂停、恢复、失败重试和部分结果可用。

## 非目标

- 第一版不实现多人协作、账号体系和权限管理。
- 第一版不上传或托管完整素材库到云端。
- 第一版不承诺 AI 标签完全准确，用户需要可以修正标签。
- 第一版不做复杂视频剪辑、转码发布或素材版权管理。
- 第一版不做全自动文件整理为默认行为。
- 第一版不做音乐 BPM、情绪、歌词、版权和相似旋律识别。

## 推荐方案

采用“本地 Web 应用 + 本地 SQLite 索引 + 本地 ffmpeg 媒体处理 + 云端 AI API”的架构。

备选方案包括原生桌面 App 和纯后端解析引擎。原生桌面 App 产品感更强，但初期会被打包、权限和跨平台文件访问分散精力。纯后端解析引擎能更快验证技术流水线，但不能完整验证素材浏览、筛选和预览体验。因此第一版选择本地 Web 应用，兼顾产品体验和实现速度。

## 系统架构

系统分为本机运行部分和云端 AI 能力部分。

本机运行部分包括：

- Web UI：展示主题、筛选器、素材墙、视频帧预览、字幕片段和队列状态。
- 本地服务：扫描目录、监听增量导入、调度解析任务、暴露本地 API。
- 媒体处理：使用 ffmpeg 读取视频时长、生成缩略图、抽取关键帧、提取音频片段。
- 本地索引：使用 SQLite 保存素材、帧、标签、字幕、主题、任务状态和错误信息。
- 原始素材目录：默认只读访问，除非用户明确执行整理操作。

云端 AI 能力部分包括：

- 语音识别和翻译：识别视频中的中文、英文、俄文谈话内容，按时间段保存字幕。
- 视觉理解：识别图片和视频帧中的物体、场景、动作、人物属性和业务标签。

系统只上传解析所需的帧图、压缩图片或音频片段，不默认上传完整原视频。

## 核心界面

第一版界面由三块组成：

- 左侧导航：主题或集合、导入来源、后台解析队列摘要。
- 中间素材墙：搜索框、多标签筛选器、素材卡片网格。
- 右侧详情面板：当前素材详情、视频帧预览、时间点、标签、字幕片段、文件信息。

在“牛仔面料工厂”主题中，用户可以点击“裁剪布料”“缝纫机”“俄文”“有谈话”等标签逐步缩小结果。点击某条 5 分钟视频素材后，右侧展示代表帧预览。默认抽帧策略不会机械生成过多帧，但用户可以对单个视频开启精查模式，按每 3 秒抽帧生成约 100 张预览图。

## 视频解析策略

视频解析采用混合抽帧策略：

- 默认使用关键帧或场景变化抽帧，减少重复画面。
- 设置最长间隔兜底，例如至少每 5 到 10 秒保留一帧。
- 对单个视频支持精查模式，例如每 3 秒抽一帧。
- 每个帧记录时间点、缩略图路径、画面标签和置信度。
- 视频音频被提取为适合云端语音识别的片段，识别结果保存为带时间范围的字幕片段。

这个策略兼顾成本、预览质量和精细盘点能力。

## 图片解析策略

图片解析包括三类信息：

- 文件基础信息：路径、文件名、大小、创建或修改时间、hash。
- 元数据：EXIF、拍摄时间、GPS 地点信息、相机信息。
- 画面内容：云端视觉模型识别物体、场景、人物属性、动作和业务标签。

图片标签进入统一标签体系，支持与视频帧标签一起筛选。

## 主题和标签

主题和标签采用“手动为主，AI 推荐辅助”的方式。

用户可以手动创建“牛仔面料工厂”等主题，并导入相关目录。AI 可以根据标签、路径、文件名、字幕和视觉内容推荐主题或集合。AI 推荐结果需要用户确认后才正式归类。

标签需要支持来源和置信度：

- 系统标签：文件类型、路径、时长、语言、是否有字幕。
- AI 标签：牛仔布、裁剪布料、缝纫机、人物、产品册等。
- 用户标签：用户手动增加或修正的标签。

系统应支持同义词归一，例如“牛仔布”“denim fabric”“denim”可以归并到同一标签组。

## 数据流

素材从导入到可搜索经历以下步骤：

1. 用户导入本地目录或移动硬盘目录。
2. 系统扫描文件，读取路径、大小、修改时间、hash、EXIF、视频时长和文件类型。
3. 新增或变更文件写入 SQLite，并创建解析任务。
4. 本地预处理生成缩略图、视频帧、音频片段和基础元数据。
5. 云端 AI API 处理必要的帧图、压缩图片或音频片段。
6. 系统保存视觉标签、字幕片段、语言信息和置信度。
7. 标签归并和主题推荐任务补充搜索索引。
8. UI 展示已完成或部分完成的结果，用户可以筛选、搜索和修正。

## 主要数据对象

- LibrarySource：导入来源目录、显示名称、扫描开关、上次扫描时间。
- Asset：素材文件路径、文件类型、大小、hash、修改时间、时长、EXIF、解析状态。
- VideoFrame：所属视频、时间点、缩略图路径、抽帧策略、帧标签。
- TranscriptSegment：所属视频、开始时间、结束时间、语言、原文、可选翻译。
- Tag：标签名、标签类型、来源、置信度、标准化名称。
- AssetTag：素材或帧与标签的关联。
- Collection：手动主题或 AI 推荐主题。
- CollectionAsset：主题与素材的关联。
- AnalysisJob：解析任务、阶段、状态、重试次数、错误信息。

## 任务状态

解析任务支持以下状态：

- pending：文件已入库，等待后台处理。
- processing：正在抽帧、提音频或调用 AI。
- partial：部分结果可用，例如有缩略图但字幕未完成。
- done：当前解析策略下处理完成。
- failed：任务失败，记录错误原因，可重试。
- skipped：文件类型不支持、文件过大或用户跳过。

文件级和阶段级状态都需要落库，确保应用重启后可以继续处理。

## 错误处理

系统将失败视为正常情况处理。常见失败包括：

- 移动硬盘断开或目录不可访问。
- 原始文件被移动、删除或重命名。
- 视频损坏或格式不支持。
- ffmpeg 抽帧、读取时长或提取音频失败。
- 云端 API 超时、限流、余额不足或返回异常。
- 图片或视频过大，超出配置限制。

每个失败任务保存阶段、错误类型、错误消息和发生时间。用户可以单文件重试、批量重试、跳过或重新扫描来源目录。对于 partial 状态，系统从未完成阶段继续补跑，而不是整文件重跑。

## 隐私和成本控制

系统需要清楚标示哪些内容会被上传给云端 AI。默认策略是：

- 视频不上传完整文件，只上传抽出的代表帧和必要音频片段。
- 图片上传压缩后的分析版本。
- API Key 保存在本机配置中。
- 解析结果缓存在本地，重复文件复用已有结果。
- 支持每日或每批次预算上限、并发上限和精查模式开关。

用户开启每 3 秒精查模式前，界面应提示可能增加抽帧数量和云端调用成本。

## 测试和验收

MVP 验收重点是流程闭环可靠，而不是 AI 标签完全准确。验收标准包括：

- 可以导入一个本地目录，并在素材墙中看到文件。
- 可以增量发现新增文件，并加入后台解析队列。
- 视频可以生成缩略图、代表帧、时间点和基础时长信息。
- 图片可以读取基础信息和 EXIF 信息。
- 云端 AI 调用结果能保存为标签和字幕片段。
- 标签筛选可以逐步缩小结果。
- 点击视频素材可以看到帧预览、时间点、标签和字幕。
- 失败任务可查看原因并重试。
- 原始文件默认不被移动、重命名或修改。

测试素材集应包含：

- 普通图片。
- 带 EXIF 和 GPS 信息的图片。
- 短视频。
- 约 5 分钟视频。
- 含中文、英文、俄文谈话的视频。
- 损坏文件。
- 重复文件。
- 位于移动硬盘或可移除目录中的文件。

## 后续扩展

第一版稳定后可以扩展：

- Electron 或 Tauri 桌面打包。
- 更强的 AI 自动聚类和主题推荐。
- 本地模型解析模式，降低长期成本。
- 批量复制、移动、重命名和导出整理结果。
- 语义搜索，例如“找工人在裁剪深色牛仔布的片段”。
- 音乐素材的节奏、情绪、BPM、歌词和版权信息整理。
- 团队素材库、共享标签和多人协作。
